# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/SiddharthKushwaha21/my-portfolio.git
```

---

## 2️⃣ Navigate To Project

```bash
cd my-portfolio
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Start Development Server

```bash
npm run dev
```

---

## 5️⃣ Open Browser

```bash
http://localhost:3000
```

---

# 📦 Production Build

```bash
npm run build
```
